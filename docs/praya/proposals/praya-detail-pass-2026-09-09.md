# Praya design detail pass — September 9, 2026

User-requested, proposed design successors. These studies do not establish new canon or assigned addresses.

Updated the latest available version of nine catalogue buildings, Old Town Corner Stores and three apartment studies. Terraced Residences R3 already contains the current design language and remains unchanged. Previous catalogue artifacts and saved versions remain available. The refreshed versions are saved in **Design library → Your designs**, named **Praya detail pass**; the starting catalogue still holds the earlier reference studies.

The pass adds recessed stained glazing where vertical full-block windows were used, shallow projecting window sills, explicit pane/bar corner connections, supported interior greenery, balanced real sign text and paired roof fan housings connected by exactly one quartz slab. Existing floor plans, furniture, district character and institutional identities are retained. Horizontal roof glazing stays full glass. BraemarHealth keeps its logo-only identity; the generic Civic Reading Room is not branded BCPL. Both clinics receive additional high-set rear privacy windows and shallow surrounds after visual review caught blank rear elevations.

This is a bounded detail update, not a full interior redesign. The simpler early studies still merit individual room-by-room work. No custom heads, bed renderer changes or world placement were performed.

Validation: all 13 compiled and saved with thumbnails, no reported walking-route issues, and no browser page errors during exterior/rear/ground-floor preview review. All 69,471 authored cells were checked against their schematic block states, including 5,095 pane/bar cells; all 23 sign texts survive export. The route approximation is not an in-game movement test. Run `JAVA_HOME=preview/.workspace/java21 node preview/check-praya-refresh.cjs` with the repository Java 21 path made absolute if needed.
