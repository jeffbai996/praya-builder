## Maintenance policy

1. Direct user statements establish decisions; explicit corrections supersede earlier statements or assistant assumptions. Record the correction and its source instead of deleting history.
2. Label entries CONFIRMED, RECORDED USER DIRECTION, OBSERVED, PROPOSED, UNRESOLVED or SUPERSEDED. Assistant prose, generated designs and specimen sign names do not become canon by repetition.
3. Preserve local variation, dates and municipality/building-specific exceptions. One reference facade is not a nationwide style rule.
4. Keep each rule in one owning file and link it from this index. Session records and output copies are evidence/snapshots, not competing rulebooks.
5. When new sources conflict, record the conflict here before applying a new interpretation. Do not invent translations, addresses, institutional history or acronym expansions.
6. New reference images should retain original filenames and be linked with provenance. Keep credentials, live private coordinates and runtime state outside canon files.
