Import existing records

Paste a JSON array of place records. Review before saving. Sources are required for verified records and boundaries; addresses need an existing street and civic number. Up to 100 records per batch.

Parcel split or merge

Use an object with records (the new parcels) and lineage: {"type":"split","parents":["existing parcel ID"],"source":"boundary decision"}. A split requires multiple new parcels; a merge requires multiple parents and one new parcel. Parents are retired atomically and kept in history. Boundaries are manually supplied; this does not calculate or certify a subdivision.
